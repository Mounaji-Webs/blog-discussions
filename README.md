# blog-discussions

Comments on the [Mounaji Studio dev blog](https://www.mounajistudio.com/blog), through [giscus](https://giscus.app).

Each post has one discussion in **Announcements**, opened by giscus the first time someone comments. Comment from the post itself, or here.

If you found a number in a post that does not hold up, this is the place. The data behind our retrieval posts is at [mounajistudio.com/blog/retrieval-data](https://www.mounajistudio.com/blog/retrieval-data/README.md), with a script that recomputes every figure.

There is no code in this repository.
